# Security policy

## Report a vulnerability

Use GitHub's private vulnerability reporting for this repository (the
**Report a vulnerability** button). If the button isn't available, open an
issue asking the maintainers for a private way to report, without sharing any
details of the vulnerability. Do not open public issues or pull requests that
describe a vulnerability, or post details in public comments.

Include the affected commit, the part of Wisp involved, the conditions that
trigger the issue, and the impact you observed. Keep API keys, tokens, private
account details, and unredacted logs or configuration files out of the report.

## Supported versions

Security fixes target the current code on the default branch. Older checkouts
are not supported separately.
